## What it does

`main.ts` writes a single-line joke about office life to `/output/entry.txt` (1–200 characters, one sentence):

> I asked for a second monitor and got a mindfulness lecture instead — apparently the screen I need is inner peace.

This is version 2 of the entry: a fresh angle (a hardware request answered with a wellness lecture) after version 1's "per my last email" joke ranked outside the top 1000 in round 1.

## Run

```sh
node main.ts
```

The output directory defaults to `output/` next to `main.ts` and can be overridden with the `MAKEFUN_OUTPUT_DIR` environment variable.
